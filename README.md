## ✨ Visão geral

Exercício orientado a objetos com entidades de acervo e fluxo de biblioteca, organizado em pacotes de modelo e controle.

## 🚀 O que você encontra aqui

- **Modelos de autor, editora, livro, locação e usuário**
- **Separação de lógica de controle e modelos**
- **Prática de relacionamentos entre entidades**

## 🧰 Tecnologias

`Java`, `POO`, `CRUD`.

## ▶️ Como explorar / executar

Abra o projeto em uma IDE Java e execute `src/controller/Main.java`. O código-fonte está em `src/model` e `src/controller`.

## 📁 Repositório

```bash
git clone https://github.com/KalleoLeandro/java-biblioteca.git
cd java-biblioteca
```

[Consultar os arquivos e o histórico do projeto](https://github.com/KalleoLeandro/java-biblioteca)

## 📝 Observações

> **Escopo:** demonstração educacional sem promessa de banco de dados ou implantação web.
